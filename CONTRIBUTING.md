# Contributing

Use the [issue forms](https://github.com/ixiehao/Any2WebP/issues/new/choose) for bugs and focused proposals. See [SECURITY.md](SECURITY.md) for private vulnerability reports.

1. Fork the repository and work on a branch off `main`. Discuss larger changes in an issue so reviewers know the intended behavior.
2. Follow the [build and test instructions](docs/DEVELOPMENT.md). For changes to conversion or export, test generated media and report the actual output format, timing, and playback behavior.
3. Open a pull request with the user-visible change, the checks you ran, and anything you could not verify. Update English, Simplified Chinese, and Japanese interface strings when behavior changes.

Use generated or redistributable media in tests. Include the source and license for any new third-party asset. Keep local build output, private files, and access credentials out of commits. Contributions to the project are accepted under the [MIT license](LICENSE).

请参考[构建与验证](docs/DEVELOPMENT.md)提交变更，在 PR 中说明实测范围，并同步更新三语界面文案和相关文档。

変更を送る前に[ビルドとテスト](docs/DEVELOPMENT.md)を確認してください。PR には確認した内容を記載し、変更した画面の三言語の文言も更新してください。
