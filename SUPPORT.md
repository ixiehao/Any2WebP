# Support / 支持与反馈 / サポート

- Get builds from [GitHub Releases](https://github.com/ixiehao/Any2WebP/releases) or follow the [source build instructions](docs/DEVELOPMENT.md).
- Use the [issue forms](https://github.com/ixiehao/Any2WebP/issues/new/choose) for a reproducible bug or feature request. For video issues, include the versions shown in **Help → Video Dependencies**. Use a sample you have permission to share.
- For a possible security vulnerability, follow the [security policy](SECURITY.md).

报告普通问题时请提供应用版本、macOS 版本、出错步骤和脱敏素材。视频转换问题可在「帮助 → 视频依赖」查看工具版本。

不具合を報告する際は、アプリと macOS のバージョン、再現手順、共有可能なサンプルを添えてください。動画の問題では「ヘルプ」から依存ツールのバージョンも確認できます。
