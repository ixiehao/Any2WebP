# Security / 安全报告 / セキュリティ

Use [GitHub private vulnerability reporting](https://github.com/ixiehao/Any2WebP/security/advisories/new) for potential vulnerabilities. Include the affected app version, macOS version, impact, and a shareable way to verify the issue. Keep security-sensitive details and private files out of public issues. Report ordinary conversion errors through the [support page](SUPPORT.md).

请通过 [GitHub 私密安全报告](https://github.com/ixiehao/Any2WebP/security/advisories/new)提交漏洞。注明受影响的应用与 macOS 版本、影响及可安全分享的验证方式。普通转换错误请走[反馈入口](SUPPORT.md)。

脆弱性の可能性がある場合は、[GitHub の非公開報告](https://github.com/ixiehao/Any2WebP/security/advisories/new)をご利用ください。対象バージョン、影響、安全に共有できる確認方法を添えてください。通常の変換エラーは[サポート](SUPPORT.md)から報告してください。
